# 帆船赛现场控制和申诉处理

源提示词摘要：竞赛官维护组别、航线、起航时间和处罚记录，计时员提交到达数据，裁判处理抗议、重赛、弃权和成绩更正；冲突或重复处罚进入复核，操作保留时间线。

## 技术栈

React 19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62024`

## 可用流程

- 计时合表：两台终端分别提交船号、本机到线时刻和本机钟差；标准时刻 = 本机读数 − 钟差。
- 合表只处理未入账记录（中断后可续跑）：同船两机校正后相差 ≤3 秒取最早一条；差太多两版并存进复核队列，暂不进入名次，裁定后重算。
- 终端钟差改动后，所有相关净用时和名次立即作废重算；已发布成绩自动标记作废并另存更正版（版本号递增、保留作废原因）。
- 竞赛控制：起航倒计时、比赛状态切换、船队和航线查看。
- 成绩管理：录入净用时和处罚秒数，标记成绩更正并发布正式成绩；发布存档可查看现行版、更正版和已作废版本。
- 抗议处理：提交抗议、进入复核、支持抗议或维持原成绩，判罚加秒同样触发名次重算与更正版另存。
- 数据使用 localStorage 持久化（`regatta-control-v2`），刷新页面后继续保留。
